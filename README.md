# 🏙️ Smart City Monitoring and Automation System

## 📌 Project Description

The **Smart City Monitoring and Automation System** is an IoT-based project developed using **Cisco Packet Tracer**. It demonstrates how Internet of Things (IoT) technology and wireless communication can be used to automate city operations, improve public safety, and reduce energy consumption.

The system uses a centralized IoT Gateway to connect and manage different smart devices. Motion detectors identify movement and automatically trigger connected devices based on predefined automation rules.

## 🎯 Aim

To design and simulate an IoT-based smart city system that provides automated security surveillance, intelligent street lighting, and restricted-area monitoring through wireless communication.

## 🎯 Objectives

* Implement motion-triggered security surveillance.
* Automate streetlights using motion detection.
* Detect unauthorized movement in restricted areas.
* Activate emergency sirens and warning lights automatically.
* Establish wireless communication between IoT devices.
* Demonstrate centralized monitoring of connected devices.

## ⚙️ Modules

### 1. Government Building Entrance Monitoring

* Detects movement near the building entrance.
* Automatically activates the security camera.
* Monitors the entrance door.
* Improves building security through automated surveillance.

### 2. Smart Street Lighting

* Uses motion detectors to identify movement.
* Automatically switches ON streetlights when movement is detected.
* Switches OFF lights when the area becomes vacant.
* Helps reduce unnecessary electricity consumption.

### 3. Restricted Area Monitoring

* Detects movement in restricted areas.
* Activates warning lights when intrusion is detected.
* Triggers an emergency siren.
* Provides an automated security alert mechanism.

## 🏗️ System Architecture

The system follows a centralized IoT architecture consisting of three layers:

**1. Sensing Layer**

* Motion Detectors

**2. Processing and Communication Layer**

* Central IoT Gateway (DLC100)
* Wireless Communication
* Automation Rules

**3. Application and Actuation Layer**

* Security Camera
* Automatic Entrance Door
* Smart Streetlight
* Warning Light
* Emergency Siren
* Administrator Smartphone

### Working Flow

Motion Detection → Wireless Communication → IoT Gateway → Automation Rules → Device Activation

## 🚀 Implementation

The project is implemented and simulated using Cisco Packet Tracer.

1. IoT devices are connected to the central gateway.
2. Wireless communication is established between the devices.
3. Motion detectors are configured to detect movement.
4. Automation rules are configured for the connected devices.
5. When movement is detected, the corresponding devices are activated automatically.
6. The system is monitored through the administrator interface.
